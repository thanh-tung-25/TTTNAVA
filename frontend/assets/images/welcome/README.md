# Hình 3D cho trang giới thiệu TTNAVA

Tạo bằng công cụ **imagegen tích hợp**, ngày 12/11/2026. Giữ nguyên logo TTNAVA, favicon và biểu tượng ứng dụng.

| Tệp | Kích thước | Dung lượng |
|---|---|---|
| `hero-3d-480.webp` — sư tử, dùng cho màn hình nhỏ | 480 × 480 | 25.416 byte |
| `hero-3d-960.webp` — sư tử, dùng cho màn hình lớn | 960 × 960 | 80.032 byte |
| `primary-3d.webp` — Tiểu học | 700 × 700 | 19.030 byte |
| `secondary-3d.webp` — THCS | 700 × 700 | 24.760 byte |
| `chinese-3d.webp` — Tiếng Trung | 700 × 700 | 31.206 byte |

Prompt đầy đủ và nguồn ảnh được lưu tại [hero-prompts.md](hero-prompts.md) và [image-prompts.md](image-prompts.md). Các ảnh nguồn được giữ nguyên; WebP chỉ tối ưu kích thước và định dạng. Không dùng API hoặc CLI trả phí.
